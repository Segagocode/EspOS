# EspOS

**Минималистичная модульная операционная система для ESP32**

Первый практический шаг к настоящей ОС на ESP32.

## Текущий статус (Этап 1)

- Модульная архитектура
- Display Manager (поддержка нескольких режимов/экранов)
- Система команд (легко расширяется)
- Shell с OLED + Serial как клавиатурой
- Готовность к дальнейшему развитию (WiFi tools, датчики, mesh)

## Железо

- **Основное**: ESP32 + OLED SSD1306 128x64 (I2C, адрес `0x3C`)
- Serial используется как клавиатура (удобно вводить с телефона)

## Структура проекта

```
EspOS/
├── EspOS.ino                     # Главный файл (удобно для ArduinoDroid)
├── config/
│   └── Config.h                  # Все настройки
├── kernel/
│   ├── Kernel.h
│   └── Kernel.cpp                # Инициализация системы
├── drivers/
│   ├── Display.h
│   └── Display.cpp               # Менеджер OLED + режимы
├── services/
│   ├── CommandRegistry.h
│   ├── CommandRegistry.cpp       # Регистрация и вызов команд
│   ├── Shell.h
│   └── Shell.cpp                 # Командная строка
└── README.md
```

## Установка

1. Установи библиотеки:
   - Adafruit GFX Library
   - Adafruit SSD1306
   - Adafruit BusIO

2. Открой `EspOS.ino`
3. Выбери плату ESP32
4. Загрузи

## Доступные команды (пока)

| Команда     | Описание                    |
|-------------|-----------------------------|
| `help`      | Список команд               |
| `clear`     | Очистить экран              |
| `dir`       | Показать содержимое "диска" |
| `mode`      | Показать/сменить режим      |
| `info`      | Информация о системе        |
| `echo`      | Вывести текст               |
