# EspOS (v0.5.0-marauder)

**Минималистичная модульная операционная система и беспроводной комбайн для ESP32**

Терминал — это ядро. Графика — дополнение.

---

## ⚡ Особенности версии v0.5.0-marauder

* **Модульная C++ архитектура:** чистая разбивка по слоям (`config/`, `drivers/`, `services/`, `kernel/`).
* **Две среды разработки одновременно:**
  * **PC / PlatformIO / Arduino IDE:** модульная разработка.
  * **Android / ArduinoDroid:** автоматическая генерация единого монолитного файла через `python tools/bundle.py` в папку `ArduinoDroid/EspOS.ino`.
* **Marauder Wireless Tools:**
  * `scan` — быстрое сканирование 2.4 ГГц эфира с определением RSSI, каналов и шифрования.
  * `beacon [ssid]` — генерация и спуфинг 802.11 маяков (Beacon Frames) с возможностью циклического спама фейковых точек доступа.
  * `pktmon [ch]` — «живой» графический анализатор трафика в режиме promiscuous с отрисовкой бегущей гистограммы и детектором атак деаутентификации.
* **TUI Терминал & Экранная клавиатура:**
  * Полноценная виртуальная консоль DOS-стиля на 2.8" SPI TFT (ILI9341).
  * 5-рядная экранная клавиатура с тач-управлением (XPT2046).
  * Параллельный двусторонний ввод команд через USB Serial (115200 бод).
* **Файловая система LittleFS (`CORE:\`):**
  * Нормализация путей, поддержка `.` и `..`.
  * Команды: `ls` / `dir`, `cd`, `pwd`, `cat`, `write`, `rm`, `mkdir`.
* **Сетевой стек & Беспроводная прошивка:**
  * `wifi [ssid pass]` — статус сети и подключение с автосохранением в `/config/wifi.cfg`.
  * `update <url>` — OTA-прошивка с визуальным прогресс-баром на экране.

## 💻 Сборка и прошивка

### На ПК (через PlatformIO)
```bash
# Сборка
pio run

# Прошивка (при необходимости удерживать кнопку BOOT)
pio run -t upload
```

### На Android (через ArduinoDroid)
1. Откройте файл `ArduinoDroid/EspOS.ino`.
2. Установите библиотеки: `Adafruit GFX`, `Adafruit ILI9341`, `XPT2046_Touchscreen`.
3. Скомпилируйте и прошейте плату.
