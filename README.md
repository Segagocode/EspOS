# EspOS

**First practical realisation of an OS on ESP32**

Простая оболочка (shell) для ESP32 с выводом на OLED-дисплей SSD1306.

Это первый шаг к созданию настоящей операционной системы на ESP32.

## Возможности

- Терминал в стиле DOS/командной строки
- Вывод на OLED 128x64 (SSD1306)
- Поддержка команд через Serial
- Базовая команда `dir`

## Железо

- ESP32
- OLED SSD1306 (I2C, адрес `0x3C`)

## Установка

1. Установи библиотеки:
   - Adafruit GFX Library
   - Adafruit SSD1306
   - Adafruit BusIO

2. Открой `EspOS.ino` в Arduino IDE / ArduinoDroid
3. Выбери плату ESP32
4. Загрузи прошивку
